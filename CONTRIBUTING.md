# Contributing to PHPAML Data MongoDB

Thank you for improving the official MongoDB adapter for PHPAML Data.

Search existing issues first. Report vulnerabilities privately through a GitHub Security Advisory. Never include credentials, production documents, connection strings, database dumps, or unredacted environment files.

Create a focused branch, add tests, keep English and French documentation aligned, and run `composer test`. Changes to the official transport or transactions should also run the MongoDB replica-set integration suite. Discuss new public query features or architectural changes in an issue first.

Contributions are licensed under the [MIT License](LICENSE).

## Français

Les corrections ciblées sont bienvenues. Exécutez les tests unitaires et l’intégration MongoDB concernée, ne publiez aucune donnée sensible et gardez les deux langues alignées. Toute contribution est distribuée sous licence MIT.
