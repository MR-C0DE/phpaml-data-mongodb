# Security policy

Report vulnerabilities privately with a GitHub Security Advisory in this repository. Do not disclose exploit details, MongoDB credentials, connection strings, production documents, or personal information in a public issue.

The latest pre-release and current `main` branch are supported. Older alpha releases are unsupported. We aim to acknowledge critical reports within 72 hours and provide an initial assessment within 7 days.

Include the affected package and MongoDB versions, topology, impact, minimal reproduction, and sanitized diagnostics. Only test systems and data you own or are authorized to test.
